# Image checklist

Every image below is optional — the site shows a tidy coloured placeholder
wherever a file is missing, so nothing ever looks broken. Add them as you go.

**The fast way:** `tools/README.md` walks through extracting every image from the
old Google Site automatically, at full original resolution, and filing it under the
right name here. That takes about fifteen minutes for the whole set.

**By hand:** open the old page, right-click an image, choose **Save image as…**, and
save it into this repo under the exact filename listed below. Roughly 1600 px wide is
plenty; JPG for photos.
